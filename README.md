# js-playground

A collection of JavaScript experiments, exercises and utilities.

## Getting Started

### Requirements

- Node.js
- Git (optional, for cloning the repository)

### Installation

Clone the repository:

```bash
git clone https://github.com/norsowinski/js-playground.git
cd js-playground
```

Alternatively, download the repository as a ZIP file and extract it.

### Running the Playground

Execute the JavaScript file using Node.js:

```bash
node playground.js
```

The results will be displayed in your terminal.

No external dependencies or additional installation steps are required.

## Included Utilities

| Function | Description |
| --- | --- |
| `sum(numbers)` | Calculates the sum of an array of numbers. |
| `unique(values)` | Removes duplicate values from an array. |
| `fizzBuzz(limit)` | Generates a FizzBuzz sequence. |
| `reverseString(text)` | Reverses a string. |

## Purpose

This repository is a personal playground for experimenting with JavaScript, practicing programming concepts and exploring small utilities.
